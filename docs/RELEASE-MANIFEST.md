# 发布清单：公开 /  / 私有（公开脱敏版）

> **公开版（public edition）**：仅保留对外可发布的契约与口径；不含私有路径、真实聊天片段、任务编号或逐题评测产物。

## 0. 原则

**能公开的只有"代码 + 契约 + 测试 + 合成样例"**；真实数据、模型权重、工作记录永不发布。
公开面任何一处出现私有面路径/内容，都视为发布阻断（P0）。

## 1. 公开（进开源仓库）

### 1.1 代码与样例

| 项 | 说明 |
|---|---|
| 核心模块 | 确定性执法层 + 账本 + 管道 + 身份/存储端口（纯标准库，AST 门禁已锁） |
| 测试 | 全部现有测试（合成 fixture/内存账本，不依赖私有数据） |
| 最小 demo | 端到端冒烟（合成数据） |
| 参考检索器 | 参考实现（BM25 + 字符 n-gram + RRF），带"非生产/勿报检索质量 issue"声明 |
| 根入口 | `README-OSS.md`、`LICENSE`、`NOTICE`、`LICENSE-DOCS.md`、`THIRD-PARTY-NOTICES.md`、`CONTRIBUTING.md`、`SECURITY.md` |

### 1.2 契约/规格文档

公开：三阶段发射契约、Prompt/schema 契约、语义 judge 评测契约（不含私有样本）、能力层契约、
能力边界声明（`ALGO-CEILING`）、租户/Agent 抽象、评测协议（无数据）。
以下文档**以公开版发布**（仅保留内容）：决策表、LLM-in-the-loop 报告、语义 judge 报告、
开源隔离策略、发布清单、修订记录。

### 1.3 脱敏规则（统一）

- **删除**：私有目录与私有产物名、真实聊天片段、/版本号、复核对话过程、未公开探针原文。
- **保留**：契约语义、指标定义、聚合数字、能力边界、复现方法与口径。
- 脱敏版与版**仅保留内容**，不承诺逐字一致；不能用公开版反向覆盖版。

## 2. （不发布）

说明文档、方案对齐、原始决策记录、工作约定；固定评测产物（报告与结果 JSON）；默认指向私有数据的
评测脚本（**参数化 + 合成样例后才可公开**）；任务/发布计划记录与复核记录。

## 3. 私有（永不发布）

私有数据目录全部内容（真实语料、评测探针、评测结果与人工终审清单）；模型权重与推理库；
模型评测脚本；任何密钥、token、内网地址、真实聊天逐字片段。

## 4. 导出白名单（草案，供导出脚本使用）

由白名单驱动：核心代码目录、测试目录、最小 demo、参考检索目录、公开契约文档、
脱敏版文档（从 `docs/public/` 映射到导出仓库的 `docs/` 下）、根入口与许可证文件。

**黑名单校验（导出前必须 0 命中）**：私有数据目录、绝对路径、内网地址、/版本号、
真实聊天片段、模型二进制文件（不枚举后缀，避免出现可被复制的二进制清单）、密钥模式。

## 5. 许可证与发布范围取舍

1. 代码 Apache-2.0；文档 CC-BY-4.0（随根声明文件发布）。
2. 决策表：**公开但必须脱敏**（本目录即为脱敏版）。
3. LLM-in-the-loop / 语义 judge 报告：公开（脱敏），保留聚合数字与口径说明。
4. 参考检索必须带上（放示例目录、不叫 retrieval、不依赖核心），并写明"非生产"。
5. 第三方核查见 `THIRD-PARTY-NOTICES.md`；模型权重/依赖库不随仓分发，发布前逐项核对上游许可证。

# 算法天花板声明（同步至 v4.7-meta，2026-11-14 公开版）

> **公开版（public edition）**：仅保留对外可发布的契约与口径；不含私有路径、真实聊天片段、任务编号或逐题评测产物。

> 目的：把"确定性算法能抓什么、抓不到什么"写死，避免把算法能力宣传成"能抓所有坏引用"，
> 并明确**语义残差**的处置方式（交模型判断 + 抽样审计）。

## 1. 算法能确定性抓到的（全部可复现、不调模型）

| 类别 | 判据 | 实测证据 |
|---|---|---|
| 伪造锚点 / quote 非逐字连续 | Tier 0 `anchor` / `verbatim`（偏移+连续子串） | 真实聊天探针 FPR_strict 0/71（v4.6） |
| 否定翻转（摘录型断言） | 子句级/断言级否定极性（v4.1/v4.2，0.6 摘录门控） | N_negation 7/7 |
| 时间倒置（后事作前证） | `scenario_timeline`（hard） | 场景探针 13/13 可归因 |
| 说话人范围违和 | `scenario_speaker_scope`（hard，user_fact 断言引 assistant 推测） | 场景探针 13/13 |
| 跨会话指代 | `scenario_cross_session`（soft） | 场景探针 13/13 |
| 已被更正的旧说法 | `scenario_superseded`（v4.6 起 soft，保留+「后来被更正过」） | 正对照误标 3→0；S_superseded 正常样本仍拦 |
| 过度引用（冗余引用） | `cite_set` 增量覆盖（v4.3） | 名义 19/19、配对可归因 17/19 |

## 2. 算法抓不到的（语义鸿沟，必须交模型/审计）

1. **逐字正确但语义无关**：引用了原文片段，片段也确实在账本里，但它并不支撑断言所指的事。
   机械校验只能确认"原文存在"，不能确认"它回答了这件事"。
2. **同一话题、不同事实**：断言与证据话题相同、词面接近，但事实不同（数字、对象、条件不同）。
3. **纯话题/场景适用性**：这条证据在当前语境是否合适（过时但未被标记、场景不同但无结构信号）。
4. **模型"少引/不引"造成的无声漏证**：算法看不见未被引用的内容——由 Prompt 规则 4（有证据必须引）
   + 输出契约"无引用=未验证" + 三率评测（覆盖率/过度克制率）共同约束，但无法用执法层杜绝。
5. **表达层面的过度保守/过度自信**：措辞与证据强度不匹配（算法只按 verdict/register 给出语域上限）。

## 3. 处置原则（设计取舍）

- **能确定性抓的，全部由算法抓**（上表），不交给模型。
- **抓不到的语义残差**：生成侧由模型按 Prompt v1.2 自行判断"不适用的不引用"；
  审计侧用抽样（风险分层 + Wilson 区间）估计漏检率，报告如实标注 "unmeasured" 的部分。
- **算法只加语义标签，不改判定**；场景谓词的单侧性（封闭标记表漏检/同形误检）在
  `memory_kernel/zh.py` 和 `docs/ALGO-V4-CONTRACT.md` 逐条登记。

## 4. 本版本不承诺的事

1. 不承诺"引用正确率 100%"——只承诺"机械可验证部分 100% 通过；语义适用性由模型判断，未独立评测"。
2. 不能把 R@10 / 机械引用精度当作问答准确率。
3. 不能把小样本 LLM 评测子集（如 24 条 95.45%）推广到全量 153 条：全量 153 已完成评测，聚合数字见 `docs/public/EVAL-RESULTS.md`（逐题产物不公开）；子集数字只能按子集口径引用。
4. 场景上下文在生产链路如何注入（用户轮/claim 轮/时间来源）尚未设计，当前只在注入。
5. **证据义务元数据（F1 层）仅部分覆盖，不得表述为"已治理"**：本版本只有两条 **opt-in、soft-only**
   元数据谓词——`quantifier_generalization`（中英文**封闭量词表**参与 `no_generalization` 判定）与
   `source_attribution`（**仅由 `AnchorRecord.speaker` 派生**的 user/assistant/tool/document 最小版）。
   **不覆盖**：中文条件句（如果/要是/只要/除非/当…时）及条件对条件的结构比较（Phase 2，需先补 gold）；
   量词的完整语义强度比较与域内 recall 的 gold 度量（表外表达会漏检）；source_type 的 provenance 证据链；
   F1 原子事实持久化（`fact_id`/`status`/`supersedes`）。任何引用 `no_generalization` /
   `over_generalization` 数字的报告必须同时注明"仅元数据 soft 层 + 词表覆盖，非完整语义判定"。
   详见 `docs/F1-PHASE1.md`（实现口径/未覆盖/验收）。

6. **A2 第三方可验证归属 / 第三方可验证归属：已取舍不提供**——当前只保留**本机可审计**的写入者槽位（writer/speaker 元数据），不承诺第三方独立验证。
7. **L0 删除/遗忘未实现**：本核心只有只追加账本，不提供删除/遗忘机制（删除权设计后置；生产代理层的删除/加密销毁不在本内核内）——不提供「可删除/可遗忘」。
8. **语义真值不承诺**：本层只判「引用是否机械合法/可核验」，不判「断言是否为真」；逐字正确但语义无关的引用仍会通过（见 §2）。

## 5. 复核方式

- 每新增一个谓词/规则：`docs/ALGO-V4-CONTRACT.md` 增一条，`tests/` 增正反例，
  `<私有产物，不随仓库发布>` 增实测（FPR/TPR 必须带）。
- 任何"提升"必须带对照（开/关该规则），且默认 v2 行为逐字节不变。

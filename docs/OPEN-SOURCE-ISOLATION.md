# 开源准备：核心代码隔离（公开脱敏版）

> **公开版（public edition）**：仅保留对外可发布的契约与口径；不含私有路径、真实聊天片段、任务编号或逐题评测产物。

## 0. 开源取舍（结论）

**能公开的只有"代码 + 契约 + 测试 + 合成样例"**；真实语料、模型权重、私有评测产物、工作记录
永不发布。

| 类别 | 结论 |
|---|---|
| 核心代码（确定性执法层/账本/管道/身份与存储端口） | 公开（纯 Python 标准库） |
| 契约/协议/能力边界文档 | 公开（见发布清单） |
| 测试 | 公开（全部使用合成 fixture / 内存账本） |
| 参考检索器 | 公开为**参考实现**，`DO NOT USE IN PRODUCTION`，非核心 API 依赖 |
| 私有语料/评测探针/评测产物/模型权重/记录 | **永不公开** |

## 1. 目录边界（三分法）

1. **公开面**：核心代码 + 测试 + 契约文档 + 合成样例 + 参考检索。
2. **面**：开发过程记录、取舍记录、说明文档、脚本与固定评测产物。
3. **私有面**：真实语料、评测探针、模型权重、密钥与任何真实聊天逐字片段。

红线：公开面**不得**出现私有面路径/文件名/内容，也不得出现绝对路径与内网地址。

## 2. 开源前必须通过的硬规则

1. 核心代码仅依赖 Python 标准库；**执法路径不 import 网络/模型库**（AST 门禁）。
2. 测试与 demo 只用合成数据，`python -m unittest discover -s tests` 在干净环境全绿。
3. 公开面零命中：私有目录名、绝对路径、内网地址、/版本号、密钥模式、大二进制。
4. 真实语料与探针**不导出**；需要示例时用合成 smoke fixture。
5. 许可证齐全：代码 Apache-2.0、文档 CC-BY-4.0 与第三方声明齐备。
6. 脱敏版文档与版**仅保留内容**——不承诺逐字一致，也不能用公开版反过来覆盖版。
7. 发布前人工复核导出清单 + 自动泄漏门禁双通过。

## 3. 导出流水线（建议）

1. 白名单驱动导出（契约文档/测试/核心代码/demo/许可证/根入口文档）；
2. 导出后运行泄漏扫描（私有路径、绝对路径、编号、密钥、二进制）；
3. 在干净环境跑一遍测试与 demo（不依赖本机私有数据）；
4. 人工复核 diff 与清单；任何一步失败即停止发布。

## 4. 许可证与第三方

- 代码：Apache-2.0（根 `LICENSE` + `NOTICE` + `THIRD-PARTY-NOTICES.md`）。
- 文档：CC-BY-4.0（`LICENSE-DOCS.md`）。
- 模型权重不在仓库内分发：只给下载脚本与许可证说明；引用上游库须核对许可证。

## 5. 公开文档面

- `README-OSS.md`：是什么/不是什么、快速开始（合成数据）、契约入口、能力边界。
- `CONTRIBUTING.md`：开发环境、测试、提交规范、禁止提交私有数据。
- `SECURITY.md`：漏洞报告渠道；**不得**在 issue 里贴真实聊天/探针/密钥。
- API 稳定性：v0.x 允许破坏性变更，但契约文档变更必须升版本号并给迁移说明。

## 6. 探针与真实语料的处理

- 真实探针集与真实语料含逐字片段，**不整体开源**；只公开"评测协议 + schema + 很小的合成 smoke fixture"。
- 理由：脱敏后保真度/可比性都会失真，公开反而误导（"合成指标 ≠ 真实指标"）；真实探针本身是评测资产。

## 7. 参考检索（可选，非核心 API）

- 定位：**reference baseline**，只为让执法层可端到端跑起来；不是最佳实践、不是核心依赖。
- 实现：词面 BM25 + 字符 n-gram + RRF，纯 stdlib、确定性。
- 文件头写死 `DO NOT USE IN PRODUCTION`；README 说明"检索是商品化能力，勿报检索质量 issue"。
- 已知负结果写进文档，避免贡献者重复踩坑：cross-encoder 精排为负贡献；全库 dense 融合不救召回；
  问句改写 + 偏好守卫的 dense **条件路由**另经单次评测 采纳，但**不在参考检索器内**。
- 检索只在生成前使用，**不进执法层**（执法不调模型）。

## 8. 开源前验收清单

- [ ] 核心代码与 demo 无私有路径/绝对路径/脚本名
- [ ] 核心 AST 扫描仅标准库、无网络/模型导入
- [ ] 干净环境 `python -m unittest` 全绿（不依赖私有数据）
- [ ] 泄漏门禁 0 命中（私有路径/真实片段/密钥/大二进制）
- [ ] 许可证 + SPDX 头 + 第三方声明齐全
- [ ] 导出清单人工复核通过
- [ ] 未公开文档不在导出清单

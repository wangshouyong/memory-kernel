# 评测总览：我们目前能达到什么程度

> 只发布**聚合指标**：不含数据集、探针、真实聊天片段、逐题产物与私有路径。
> 数据分三类：`public`（公开基准）/ `internal_synthetic`（合成探针）/ `internal_desensitized`（真实聊天脱敏后评测）。

---

## 1. 一句话结论

**生成和检索都会出错，确定性执法层负责把错误挡在用户看到之前。** 它把每条 claim 映射到四语域
（fact / hedged / unknown / speculation），让模型从"强行输出"变成"如实认怂"：假引用被删、无证据标记未验证、
有歧义加 hedge、推测加前缀。它不是"让模型更聪明"，而是让回答**可核验、可审计**。

## 3. 数据来源：用户本人真实聊天，不是临时构造

**153 条探针全部来自用户本人的真实聊天记录**，不是为评测编造的数据：

- **DeepSeek 网页版官方导出**：660 会话 / 9,039 条消息，时间跨度约 **2025-02 → 2026-11（约 21 个月）**；
- **豆包网页端抓取**：30 会话 / 1,341 条消息，**2026-06 → 2026-11（近 5 个月）**；
- 清洗（去系统通知/重复/污染会话/低中文比例）后保留 **502 会话 / 8,219 条消息**（DeepSeek 473 + 豆包 29）；
- **153 条探针（claim→evidence 与 LLM 问答同源）从这些真实会话的候选消息中确定性构造**：claim/quote 直接取自真实消息原文，
  标签由构造规则定义（逐字/转述/否定/数字/说话人/跨会话/部分覆盖/无关等 19 类）。

原始会话与逐条探针内容**永不发布**（隐私与评测资产），只发布聚合指标。

## 4. 真实限制：我们做不到什么（物理边界）

| 限制 | 数字 / 事实 | 原因 |
|---|---|---|
| 纯词面检索有上限 | 全库 R@10 **77.78%**、去偏差 **64.29%**、R@3 68.63% | 词面只匹配共享 token：同义改写、代词/省略、跨会话指代天然丢召回 |
| 隐式状态冲突无法靠词面发现 | STALE TPR **3.0%** vs FPR **2.25%**（统计上无判别力） | 需要 (subject, attribute, value) 状态槽或离线抽槽；词面 `same_fact` 不是防线 |
| 负例仍有漏检 | **4/82（4.9%）** 被误判 verified；硬负例 strict 只拦 **40.6%**，其余只能降级 | 确定性谓词能验"是否逐字/极性/说话人/时间"，**不能判"语义是否切题"** |
| 转述类不能 verified | **19/20 只能降级**，仅 1/20 verified | verified 要求逐字引用；转述只能 hedge，这是严格口径的代价 |
| 语义 judge 也不完美 | 特异性 **58.8%**、转述敏感性 **20%**、`N_speaker` strict **0/6** | judge 本身是模型，会漏判转述/说话人；语义指标只作上界 |
| 生成侧是最大短板 | 端到端演示生成 p50 **28.5s**、judge fail **8/10**、gold 要点覆盖 p50 **0** | 生成模型决定内容质量；执法层只保真，不能创造正确内容 |
| 153 条是 claim→evidence | 不是 question→evidence | 指代/省略、完整问答链路未被评测覆盖 |

**一句话**：检索和生成会出错是词面与生成模型的物理极限；执法层不解决"更聪明"，只解决"别把假话说成真的"。

## 5. 防幻觉兜底：四语域让模型"如实认怂"

执法层把每条 claim 映射到 `memory_kernel/registers.py` 的四语域（`fact / hedged / unknown / speculation`），
用户看到的永远是"证据允许的最强语气"：

| 情形（抽象） | 门控结果 | 语域 | 用户看到的（抽象示例） |
|---|---|---|---|
| 引用逐字且全部谓词通过 | verified | **fact** | "根据记录，…" |
| 引用在，但覆盖不完整/有歧义/证据不完整 | degraded | **hedged** | "我记得…，但这条在限定条件上可能有歧义 / 还没核实过" |
| 引文被改、否定翻转、说话人错位、引用指向已更正记录 | rejected | （删除该句） | 不把假引用递给用户 |
| 断言没有任何可引用证据 | 无引用 | **unknown** | "这件事我不记得了 / 我给不出可核验的依据" |
| 模型自己想推测 | speculation | **speculation** | "按我过去的经验推测…（无记忆依据）" |

**聚合效果**：153 条真实问答里模型 **238 条 claim 想直接输出** → 最终 **fact 192 / hedged 8 / unknown 35 / rejected 3**（46/238 未按原样呈现）；
153 条探针里 **82 条错误引用被拦/降级 78 条（95.1%）**，**71 条真实引用 0 条被硬拒**；
端到端端到端演示 **102 claim → 53 fact / 37 hedged / 12 rejected（49 条被改写或删除）**；TimlMemBench 接入执法层后 strict@10 **+16.30pp（en）/ +19.00pp（zh）**。

> 抽象 Case（只描述判定路径，不含任何真实对话文本，也不代表真实用户）：
> - 用户问："他那个项目搞完没" → 无可用证据 → **unknown（未知）** → "这件事我不记得了"
> - 引用了真实记录但转述 → **hedged** → "我记得…，但这条还没核实过"
> - 模型想猜时间/数字 → **speculation** → "按我过去的经验推测…（无记忆依据）"
> - 逐字引用 + 谓词全过 → **fact** → "根据记录，…"

它的价值不是"让模型更聪明"，而是**把模型的强行断言降级成承认不知道**：用户拿到的是可审计的"认怂"，而不是通顺的幻觉。

## 6. 数据与隐私边界

- **不发布**：`probes.jsonl`、任何真实聊天的具体文本切片、逐题评测产物、私有语料路径、模型权重。
- **只发布**：指标汇总、评测协议/口径、抽象化 Case 描述（如 §5 的"用户问 → 系统判定"形式，均为抽象示例，非真实对话）。
- 导出流水线内置机检：真实语料片段门禁（抽样 120 会话、16 字 CJK 窗口 **0 命中**）、个人特征切片门禁
  （**全量 502 会话**、12 字窗口且含人称/个人信息线索 **0 命中**）、PII 正则 **0 命中**。

## 7. 适用 / 不适用

**适用**：需要"回答里每条事实可追溯到不可篡改证据、引用可机械核验"的场景（审计、合规问答、高价值长记忆助手）。
**不适用**：把本系统当"语义真理机"（逐字但无关的引用仍会通过机械检查）；把参考 BM25 当生产检索质量；
依赖隐式状态冲突自动发现（当前无判别力，需状态槽）；独立中文跨语言检索能力。

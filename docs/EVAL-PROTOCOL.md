# 评测协议 v1（引用执法链阈值与规则校准）

> 适用范围：Tier 1 骨架的任何阈值（τ、IDF 权重、硬单元规则）与规则组合。
> `docs/EVAL-RESULTS.md`（含 n 与口径，不含逐题探针）。
> 目的：防止"用简单负样本刷出高 TPR"和"用约束生成的正样本刷出低 FPR"。
> 任何报告若不符合本协议，其数字不得用于参数锁定。

## 1. 样本定义

### 正样本（应 verified）
- **P1 约束生成**：prompt 明确要求逐字复制证据片段时产出的忠实 claim。
- **P2 自由生成**：不要求逐字、只要求有依据时产出的 claim。
- 必须分别报告两套分布。P1 是**乐观估计**（提示词把模型推向原文），不得单独用于锁定 τ。

### 负样本（应 degraded/rejected）
| 类 | 定义 | 难度 |
|---|---|---|
| N1 跨话题错配 | 断言取 A 内容，引用指向完全无关的 B | 易（接地率≈0） |
| N2 相邻轮错配 | 引用同会话相邻轮（同话题、共享大部分实体） | 中 |
| N3 谓词错配 | 实体对、谓词错（A 买了车 vs 证据 A 卖了车） | 难 |
| N4 数字/日期错 | 实体对、谓词对、数字或日期错（March 5 vs March 15） | 难 |
| N5 部分引用 | 需两条证据的组合断言只引用一条 | 中 |
| N6 改写/捏造/归属翻转 | 非子串、拼接、换说话人 | 易（Tier 0 已覆盖） |

**目标线只对 N2/N3/N4/N5 计**。N1/N6 的拦截率仅作回归哨兵，不作为优化目标——它们已经被 Tier 0 或常识性接地覆盖。

## 2. 标签来源与偏置
- 正样本标签来自 Tier 0（逐字 + 谓词全过）。Tier 0 与 Tier 1 正交，可以这样用，但必须声明。
- **precision 必须独立测量**：对 verified 子集，用离线标注（允许调用模型，但绝不进 `enforce()` 路径）判定"该 claim 是否真的被引用证据支持"，给出 point estimate + 95% CI。没有 precision 的 TPR 优化是危险的。
- 离线标注的模型、prompt、抽样率必须写进报告，保证可复现。

## 3. 统计口径
- 样本来自 10 段对话（LoCoMo），存在**聚类相关**。置信区间用**按对话的 cluster bootstrap**，不得用 iid Wilson。
- 报告必须给 per-conversation 分布，而不只是总体均值。
- 检索未命中 gold 的问题不参与 Tier 1 阈值校准（否则"模型答不出"混进判定质量），单独统计。

## 4. 指标
| 指标 | 定义 |
|---|---|
| FPR | 正样本（P1/P2 分开）被非 verified 的比例 |
| TPR_easy / TPR_hard | N1+N6 / N2+N3+N4+N5 的拦截率 |
| precision | verified 中真正被支持的比例 |
| 前沿 | 在 FPR ≤ 5% 约束下，`min(TPR_hard, TPR_partial)` 的最大值 |

## 5. 停止准则（什么时候可以说"无法继续提升"）
满足任一即可声明到达当前前沿，并把目标标记为"受限于新特征/新数据"：
1. 连续两轮在同一协议下，最优点的 `min(TPR_hard, TPR_partial)` 提升 < 1pp，且离**理论上界**（当前特征集的最优可分性）< 2pp；
2. 提升必须依赖当前不允许的手段（模型进入执法路径、或引入新的外部信号），且该依赖已被明确写出。

不满足上述条件就继续迭代，不允许用"调参调到差不多"作为结束理由。

## 6. 不可违反
- **公理 B**：`enforce()` 内不得调用任何模型。外部生成/标注工具只能用于测试数据生成与离线标注，不得进入执法路径。
- 每个数字必须标注 `SkeletonPolicy.version`。
- 每个数字必须能由仓库内脚本重跑得到。

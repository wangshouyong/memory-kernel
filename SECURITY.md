# Security policy

## Reporting a vulnerability

Please report security issues **privately** to the maintainers (do not open a public issue
for exploitable problems). Include a minimal reproduction and the affected version.

## What this project is not

- It is not a hosted service and ships no credentials or keys.
- The ledger is an append-only local structure verified with a symmetric HMAC key; possession
  of the key allows forging records (it does **not** provide third-party non-repudiation).
- Model weights, private corpora, and evaluation probes are never part of this repository.

**Never paste real chat transcripts, personal data, or credentials into issues or PRs.**

# Contributing

Thanks for helping improve the deterministic enforcement kernel.

## Ground rules

- **Do not submit private data.** No real chat logs, personal data, credentials, or model
  weights. Tests must use synthetic fixtures only.
- Keep the core pure Python standard library. `memory_kernel/` must not import network or
  model libraries; the AST isolation test enforces this.
- Run the suite before opening a PR: `python -m unittest discover -s tests`.
- Contract changes require a version bump and a migration note in the relevant
  `docs/*-CONTRACT*.md`.
